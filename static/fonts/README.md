Fonts vendored for fully offline web UI (no Google Fonts request at runtime).

- Outfit — SIL Open Font License 1.1 (https://github.com/Outfitio/Outfit-Fonts)
- JetBrains Mono — SIL Open Font License 1.1 (https://github.com/JetBrains/JetBrainsMono)

Subsets: latin, latin-ext, vietnamese (JetBrains Mono only; Outfit has no
vietnamese subset upstream, missing glyphs fall back to the system font).
